# software-quality-engineering

```mermaid
graph TD

%% === ПОЧАТОК ===
Start([Початок]) --> A[Перегляд каталогу товарів]

%% === ВИБІР РОЛІ ===
A --> B{Тип користувача?}

%% === ГОСТЬ ===
B -- Гість --> G1[Перегляд товарів як гість]
G1 --> G2[Перегляд деталей товару]
G2 --> G3{Бажає придбати товар?}
G3 -- Ні --> G4[Продовжити перегляд]
G3 -- Так --> G5[Створення облікового запису]
G5 --> R1[Вхід до акаунта]

%% === ЗАРЕЄСТРОВАНИЙ КОРИСТУВАЧ ===
B -- Зареєстрований користувач --> R1[Вхід до акаунта]
R1 --> R2[Вибір товару]
R2 --> R3[Перегляд деталей товару]
R3 --> R4[Додати до кошика]
R4 --> R5[Перегляд кошика]
R5 --> R6[Оформлення замовлення]
R6 --> R7[Автоматичне заповнення даних]
R7 --> R8[Підтвердження замовлення]
R8 --> R9[Отримання підтвердження в акаунті та на email]
R9 --> EndUser([Завершення — зареєстрований користувач])

%% === АДМІНІСТРАТОР ===
subgraph "Адміністратор"
  A1[Вхід в адмін-панель] --> A2[Додавання нових товарів]
  A1 --> A3[Редагування товарів]
  A1 --> A4[Перегляд замовлень]
  A4 --> A5[Обробка замовлень]
  A5 --> A6[Зміна статусу: в обробці / доставлено / скасовано]
  A6 --> A7[Повідомлення клієнта про статус]
end

%% === ВЗАЄМОДІЯ ===
R8 -->|Інформація про замовлення| A4
```
